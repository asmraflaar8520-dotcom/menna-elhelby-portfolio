# الموقع التعريفي للأستاذة منه خالد الهلبي — معلّمة مادة الرياضيات

موقع شخصي تعريفي فاخر للأستاذة **منه خالد الهلبي**، معلّمة مادة الرياضيات للمرحلتين الابتدائية والإعدادية حضورياً وعبر الإنترنت.

## 🌟 مميزات الموقع
- **تصميم فاخر بألوان مخصصة**: الوردي المخملي، البيج الحريري، والذهبي الملكي الشمبانيا.
- **موجّه بنسبة 100% للهواتف الذكية (Mobile-First)**: خفيف وسريع، مع منع أي تداخل للأيقونات، وقائمة تنقل زجاجية متطورة.
- **محتوى تربوي إيجابي**: يركز على الفهم والتأسيس والتشجيع وبناء الثقة لدى الطلاب.
- **تواصل فوري مباشر**: ربط سريع ومباشر بحسابات الواتساب، الفيسبوك، والبريد الإلكتروني.

## 🚀 التقنيات المستخدمة
- **HTML5 & Semantic Markup**: هيكلية متوافقة مع معايير الـ SEO وقابلية الوصول.
- **Vanilla CSS3**: تأثيرات الزجاج الفاخر (Glassmorphism)، انيميشن ناعم، وتصميم متجاوب لجميع الشاشات.
- **JavaScript (ES6+)**: تفاعلات ذكية مع مراعاة سرعة الشحن وتوفير طاقة المعالج على الهواتف.

## 📍 قنوات التواصل الرسمية
- **نظام الحصص**: حضوري مباشر + أونلاين
- **بوابات التواصل**: متاحة ومحمية بالكامل عبر الموقع الرسمي لضمان خصوصية البيانات وحمايتها من الجمع الآلي (Anti-Scraping Protection).
- **الموقع الإلكتروني الرسمي**: [menna-elhelby.vercel.app](https://menna-elhelby.vercel.app)
